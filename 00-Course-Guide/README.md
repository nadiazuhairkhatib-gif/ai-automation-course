# Course Guide

Welcome to the AI Automation Course.

This guide explains how the course works, how you will learn, how you will use GitHub, how you will submit your work, and how your progress will be evaluated.

---

## How This Course Works

This is a hands-on engineering course.

You will not learn primarily by watching demonstrations or memorizing AI tools.

Each unit follows a learning cycle:

**Challenge → Attempt → Concept → Build → Test → Diagnose → Improve → Transfer → Prove**

You are expected to participate, build, test, make mistakes, and explain your decisions.

---

## Your Learning Journey

Throughout the course, you will move through six levels:

1. Understand
2. Design
3. Build
4. Debug
5. Explain
6. Transfer

The goal is to move from using AI to engineering with AI.

---

## The Course Hub

This repository is the Course Hub.

It contains:

- Challenges
- Concepts
- Guided builds
- Independent practice
- Testing materials
- NOVA activities
- Submission instructions
- Resources

Use the Course Hub to learn and follow the course.

---

## Your Student Repository

Your personal work belongs in your private Student Repository.

Your Student Repository is where you will keep:

- Projects
- Documentation
- Test cases
- Failure logs
- Evidence
- NOVA work
- Final submissions

### Remember

**Course Hub = What you need to learn**

**Student Repository = What you built and can prove**

---

## Collaboration

You are encouraged to:

- Ask questions
- Discuss concepts
- Help peers understand technical problems
- Share useful resources
- Review ideas
- Participate in debugging discussions

However, your submitted work must represent your own understanding and contribution.

---

## Start Here

Before opening any AI tool:

1. Read the unit challenge.
2. Attempt the problem.
3. Discuss your approach.
4. Learn the relevant concepts.
5. Build the guided solution.
6. Test it.
7. Analyze failures.
8. Build an independent variation.
9. Transfer the learning to NOVA.
10. Submit your evidence.

> **Do not start with the tool. Start with the problem.**
